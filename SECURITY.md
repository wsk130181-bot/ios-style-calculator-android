# Security Policy / 安全策略

## Supported Versions / 受支持的版本

We currently provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability / 报告安全漏洞

If you discover a security vulnerability in this project, please **do NOT** open a public issue. Instead, report it privately:

1. Go to the **Security** tab of this repository on GitHub.
2. Click **"Report a vulnerability"**.
3. Provide a detailed description of the vulnerability, including:
   - Steps to reproduce
   - Affected versions
   - Potential impact
   - Any suggested fix

We will acknowledge your report within **7 days** and provide a more detailed response within **30 days**.

如发现本项目的安全漏洞，**请勿**公开提交 issue。请通过以下方式私下报告：

1. 进入本仓库 GitHub 页面的 **Security** 标签页。
2. 点击 **"Report a vulnerability"**。
3. 详细描述漏洞，包括：
   - 复现步骤
   - 受影响的版本
   - 潜在影响
   - 建议的修复方案

我们将在 **7 天内**确认收到报告，并在 **30 天内**给出详细回复。

## Scope / 范围

This security policy covers:
- Calculator engine logic and edge cases
- Android manifest and permissions
- Any third-party dependencies

This does **not** cover:
- Android OS itself
- Third-party apps installed alongside this calculator
